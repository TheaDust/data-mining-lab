# 实体定义规范

三景区使用同一套规则；以正文中当前出现的语义决定类别，景区归属字段始终来自文档，不由预测实体推断。识别范围是完整 clean_text（包括保留的标题和列表）；只标和实际或计划游览有关系的提及。

| 标签 | 定义及边界 | 正例 | 反例 / 歧义裁决 |
|---|---|---|---|
| POI | 可辨识且可作为访问点、路线节点、出入口或交通站点的名称；取完整连续名称 | 午门、断桥残雪、黄龙九寨站、九寨沟原始森林站中的完整站名 | 左线、右线是路线分组；景区门口、栈道等泛称不标；只叙述背景的杭州不标。原始森林在九寨沟指命名访问点时可标；地铁站名是 POI。 |
| TRANSPORT | 文本明确的移动方式或具体线路，保留有意义的原文形式 | 步行、徒步、坐船、地铁 1 号线、观光车 | 进入、走、乘车等泛动作不标；游船联票是票务商品；站名与方式分别处理，不把站名内的“地铁”重复标注。 |
| TIME | 对游览、开放、预约或交通有用的日期、时点、时段或时长；保留数值单位、约数、限定和连续范围 | 10.17、第二天、18:10、中午12点前、约10分钟 | 南宋、历史叙述中的 1900年、撰稿时间、距离和价格不标；“游览时间20分钟”取“20分钟”，“约10分钟车程”取“约10分钟”。“上午票”若用于说明入园时段取“上午”。 |

父景区与子景点独立提及时均可标注；单一全名中不再标注嵌套简称。不同位置的同形实体逐条计数；同形异义仅保留语义适用的出现。字符区间为 Python Unicode 码点的 0-based [start,end)，不改写空格、换行、数字和标点。冲突消解记录异常；可定位不代表类别和边界正确。

## 六组样本收尾时补充的核验口径

以下口径用于解释既有结果。上方保留原规范，两轮 Prompt 和历史输出保留原样。

- POI 采用可辨识的访问点或交通节点。具名主沟、站点、明确的站点简称及在正文中独立出现的景区历史别名均可保留。城市背景、组织名里的地名和仅用于分组的路线标签排除。集合名只有在语境中指向可定位的整体访问点时才按 POI 考虑。“西湖十景”作为主题或集合、“上下季节海”作为合称以及图件索引中的地名，在初审时单列歧义。学生抽查确认当前语境下排除“西湖十景”，保留完整合称“上下季节海”及图件索引中明确指向景区的“紫禁城”。合称内部恰好匹配的子景点字面不能当作一次独立提及。
- TRANSPORT 可采用工具名或明确方式的动宾短语，例如“观光车”“坐船”。“坐车”按原规范中的“乘车”处理，在工具种类未明示时暂排除。若采用更粗粒度交通分类，应重新统一审定此类表达。
- TIME 依据时间所限定的行为判定。游览、预约、开放和出行安排纳入，历史背景和资料整理时间排除。共同约束一次预约的“提前7天的20:00”允许按连续复合表达整体保留，独立的备选时段如“清晨或傍晚”分别记录。
